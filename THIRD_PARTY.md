# Third-party software and data

This repository includes, or installs from lockfiles, software and data made by others. Each keeps
its own licence; the MIT licence in `LICENSE` and the CC BY 4.0 licence in `LICENSE-DATA.md` do not
apply to it.

## Included in this repository

| component | location | version | licence | source |
|---|---|---|---|---|
| DIDmultiplegtDYN (R package source tarball) | `setup/vendor/DIDmultiplegtDYN_2.3.3.tar.gz` | 2.3.3 | MIT (the `LICENSE` file inside the tarball: copyright 2024 Diego Ciccia, Felix Knau, Mélitine Malezieux, Doulo Sow, Clément de Chaisemartin) | CRAN archive; https://github.com/Credible-Answers/did_multiplegt_dyn |

The tarball is shipped unchanged because CRAN now distributes version 2.4.0. The 23 cells that the
default run re-estimates were produced with 2.3.3 under R 4.5.1. The 4 large cells (Panel 3 for
economics and chemistry, main and event-clustered) were produced with 2.4.0 under R 4.6.1, on AWS.
