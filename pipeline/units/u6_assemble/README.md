# units/u6_assemble — U6 assembly (pipeline end point: 2 analysis frames + gates + power + lock)

> The frame has **15 columns** (final).
> Real data for the two universities has been shipped: `derived/u6_ship_2026-07-10/`.

## 1. What this unit does

Joins the frozen derived tables from U3 (panel), U4 (star / arrival / academic age) and U5 (dose / output)
**into two 15-column ANALYSIS_FRAMEs** (`analysis_frame_p01/p05`: one for 1% stars and one for 5% stars,
generated by the same code in one run, D1/#1, and fed to the regressions). It then runs **five classes of quality gate**
(frame/provenance/golden/attrition/reconcile), computes the **MDE power** (power 0.80 / alpha 0.05 / clustered at the
department, #17), and seals `run_manifest.lock`.
This is the **pipeline end point, with no downstream unit**. Downstream is the econometric regression (dCDH continuous dose + robust CS + wild cluster
bootstrap), run at the analysis stage. After G1 there are no A/B/C groups; the same-generation marker and event_time are derived at the regression layer from
`age_gap` / `year−arrival` (#7, arrival year frozen) and are not stored as columns. The frame has two row sources: the treated
pair set = PAIRWISE_DOSE distinct (i,star,event) (C3); the year set = arrival±5 (including the
pre-period for the anticipation test, C1). Never-treated = #6 plan B: **the pool is empty for the two universities**
(both departments have arrival events) -> recorded, and the question is left open for the 11-university stage; the CEM
(#2, 4 variables, deliberately excluding field proximity) machinery is in place and is enabled once the pool is non-empty.

## 2. Inputs (nine sources, read-only; one assert_matches_schema per boundary)

- U0 shared library: `common/*` (schema/atomic_io/manifest/reconcile/ledger/_redlines) +
  `identity/*` (cohort.academic_age_gap, direction = star−ego; golden; exit_codes).
- U2 `person_map` (table B author_id -> person fold, so that Yves Zenou's multiple IDs do not each count as a row).
- U3 `panel` slice, 5-column projection (first-publication year + late-binding material + golden works_count; a missing person falls back to
  U1 `work_first_pub`; the robust first-publication correction applies only to star candidates, and the whole incumbent pool is left untouched).
- U4 `star_set` (current 14 columns, keyed by author_id; star first-publication year = arrival−1−academic_age)
  + `events` (11 columns; the `star_person_id` column holds the raw author_id, as in the real data).
- U5 `dose_p01/p05` (PAIRWISE_DOSE, 11 columns; only the primary dose `coupling_share` is read, never the two secondary-dose
  columns, #16) + `output` (OUTPUT 12 keys x 2, one star-excluded version each for p01 and p05).
- U0.5 table A `econ_dept_registry` (dept_key -> university canonical id bridge) + table B
  `dept_roster_panel_{monash,unsw}` (authoritative for employment intervals; modal_hint is corroboration only).
- **Provenance, double anchor**: u4 = `u4_ship_2026-07-10c` / u5 = `u5_ship_2026-07-10`;
  the loading layer verifies each artifact header (mismatch -> ProvenanceMismatch HALT); the three shared keys agree across both anchors.

## 4. How to run

```bash
cd units/u6_assemble
PYTHONHASHSEED=0 OMP_NUM_THREADS=1 \
  <SAR_HOME>/python-env/bin/python3 run_u6.py \
  --out-root "<SAR_DERIVED_ROOT>/u6_ship_YYYY-MM-DD"
```
Order: m7b-assemble -> m7c-gates (on HALT, power does not run) -> m7d-power. The resume idempotency key is anchored on the
upstream 4-tuple (if upstream changes, nothing is skipped). Exit codes = 13 provenance / 14 structure / 15 tally /
18 golden (named constants in identity/exit_codes).
